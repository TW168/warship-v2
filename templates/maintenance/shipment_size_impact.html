How To Read This Analysis

1) What the filters do

Date From / Date To: defines the shipment rows included in the analysis window.

Site: narrows the analysis to one operating site such as AMJK or TXAS.

Product Group: narrows the analysis to one product family such as SW, BP, or CT.

Exclude SAIA-IP/CWF-IP: removes those carriers before all calculations are built.

2) Core relationship used on the page

\[ W = L \times A \]

\(W\) = total shipped pounds, \(L\) = distinct load count, and \(A\) = average pounds per load. This is the base identity behind the KPI cards, charts, and detail table.

3) What each KPI card means

Latest Avg lbs/load

\[ A = \frac{W}{L} \]

This is the average weight per shipment in the latest month that can be compared to the same month last year. If it falls, each shipment is lighter on average.

Prior year line: shows the same value for the same month last year so the user can compare current shipment size versus prior-year shipment size.

Latest Load Count

\[ L = \text{distinct BL count} \]

This is the number of shipment loads handled in that latest comparable month. It measures shipment frequency, not weight.

Total lbs line: shows \(W\) for that same month so the viewer can see shipment count together with total tonnage moved.

Extra Loads from Smaller Shipments

\[ ext{Extra Loads} = W_1\left(\frac{1}{A_1} - \frac{1}{A_0}\right) \]

This estimates how many additional loads are being handled only because average shipment size became smaller versus the same month last year. Positive values mean smaller shipment size is creating extra operational work.

Why the gold frame: this card is visually highlighted because it is the operational warning KPI. It translates smaller shipment size into extra handling pressure, staging pressure, and dock activity.

Volume Change Split

\[ \Delta W = W_1 - W_0 \]

\[ ext{Load Effect} = (L_1-L_0)\frac{A_0+A_1}{2} \]

\[ ext{Size Effect} = (A_1-A_0)\frac{L_0+L_1}{2} \]

\[ \Delta W \approx \text{Load Effect} + \text{Size Effect} \]

This card explains whether the change in volume is being driven more by shipment frequency or by shipment size.

4) What each chart means

Average Lbs per Load Trend: shows \(A\) by month and year. If the line goes down, shipments are getting lighter on average.

Loads per Million Lbs (Workload Intensity): shows \(I = \frac{L}{W/1{,}000{,}000}\). If it goes up, more loads are needed to move the same tonnage.

Monthly YoY Decomposition (Lbs): splits year-over-year volume change into Load Effect and Size Effect. A negative Size Effect means smaller shipment size is hurting volume and increasing operational pressure.

5) What each table column means

Month: reporting month in YYYY-MM.

Total Lbs: monthly shipped pounds, \(W\).

Loads: monthly distinct BL count, \(L\).

Avg Lbs/Load: average shipment size, \(A = W/L\).

Loads per 1M lbs: workload intensity, \(I = L/(W/1{,}000{,}000)\).

YoY Avg Lbs/Load: prior-year same-month average shipment size.

Load Effect (lbs): portion of YoY volume change explained by load-count change.

Shipment-Size Effect (lbs): portion of YoY volume change explained by average lbs/load change.

Extra Loads: estimated additional load count caused only by smaller shipment size versus last year.

6) How to read the page

Start with the filters to define the business slice.

Use the KPI cards to understand the latest comparable month.

Use the three charts to see trend, workload intensity, and cause split.

Use the detail table when you need the exact monthly values behind the visuals.
