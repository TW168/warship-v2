How This Analysis Works

Blended ¢/lb (Method A):

\[ \text{¢/lb} = \frac{\sum (\text{Unit\_Freight} \times \text{Pick\_Weight})}{\sum \text{Pick\_Weight}} \]

Year-over-year split (symmetric midpoint shift-share):

\[ \text{Mix Effect} = \sum_c (\text{share}_c^{cur} - \text{share}_c^{prior}) \cdot \frac{\text{rate}_c^{cur} + \text{rate}_c^{prior}}{2} \]

\[ \text{Rate Effect} = \sum_c (\text{rate}_c^{cur} - \text{rate}_c^{prior}) \cdot \frac{\text{share}_c^{cur} + \text{share}_c^{prior}}{2} \]

Mix Effect + Rate Effect + Residual = total ¢/lb change. The Residual is the small interaction term. A carrier/destination present in only one period is counted as mix (its missing-period rate is set equal to its present-period rate, so it does not create a phantom rate spike).

The same shift-share is applied over two parallel lenses — carrier and destination (ship-to state, from ipg_ez). Each fully explains the same total change, so the two are alternative attributions, not additive. Smaller average shipment size is shown as added context, since lighter loads raise the per-pound rate.

Market context (LMI): the verdict cross-references the latest Logistics Managers' Index Transportation Prices sub-index (parsed from the monthly LMI reports). When the rise is rate-driven and LMI Transportation Prices is high/rising, it is market-wide (lock in contracts); when it is mix-driven, it is internal and addressable regardless of the market.
