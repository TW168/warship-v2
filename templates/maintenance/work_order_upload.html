Processing Rules
  • Production line is parsed from the first 4 filename characters.
  • Sheets with names containing Timeline are skipped (case-insensitive).
  • Each processed sheet becomes one nested ticket JSON document with charting, downtime, pallets, material usage, and comments in fixed order.
  • Per-line table stores document_hash + document_payload (JSON).
  • Duplicate uploads are blocked by filename + file content hash.

Production vs. Silo Material Usage

Compares production-reported material usage (work-order tickets) against silo-derived consumption (day-over-day silo weight decrease), summed over the trailing 7 days ending on the selected date. A single day is not a fair comparison — a production ticket records one shift's usage, while silo weight is drawn down continuously, so day-level deltas are mostly timing noise.
